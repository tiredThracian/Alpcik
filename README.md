# Geçmiş Zaman Kulübü

Telefon, tablet ve bilgisayarda kullanılabilen, toplam 200 soruluk düzensiz fiil alıştırması. Sorular, 20'şer soruluk 10 quize ayrılır ve uygulama sıradaki tamamlanmamış quizi otomatik açar. Tamamlanan quiz numaraları bu tarayıcıda saklanır; cevaplar ve puanlar saklanmaz. Uygulama statik HTML, CSS ve JavaScript ile çalışır; sunucu veya veritabanı kullanmaz.

Tüm sorular ve cevap anahtarı için [SORULAR.md](SORULAR.md) dosyasına bakın.

## GitHub Pages'ta yayımlama

1. Dosyaları GitHub deposunun kök dizinine yükleyin.
2. Depoda **Settings → Pages** bölümünü açın.
3. **Deploy from a branch** seçeneğini seçin; `main` dalı ve `/ (root)` klasörünü belirtin.
4. Kaydedilen Pages adresini açın.

Google Fonts yüklenemezse metinler sistem yazı tipleriyle görüntülenir.
